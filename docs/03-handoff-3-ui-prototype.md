# 交接提示词 #3 · TeenX 全产品 UI 原型

> 本文件是开新线程搭 UI 原型的交接提示词。读取后，按页面清单逐页搭建原型，只实现页面功能与交互逻辑，不涉及任何视觉设计风格。

---

## 0. 前置与上下文

### 0.1 你的任务
搭建 TeenX 全产品的 UI 原型。TeenX 是面向 11–16 岁少年的 AI 队伍养成平台，产品由三大子系统组成：
1. **Studio（组队室）**——孩子定义、维护、迭代自己的 AI 队伍
2. **赛题与排行榜**——官方定期发赛题，孩子让队伍参战，拿分上排行榜
3. **论坛社区**——用队伍里自定义的"写帖 Agent"发帖、留言、私信、向高手学习

原型要覆盖**全部三个子系统**的所有核心页面，即使后两个子系统后端后置实现，原型里也要把页面搭出来，让整体产品形态可见。

### 0.2 原型技术栈
- React + Vite + TypeScript
- React Router
- 用 mock 数据，不接真实 API
- 不引入 UI 设计框架（如 Ant Design / MUI），用纯 HTML + 基础 CSS 把功能和布局搭出来即可
- 页面之间的跳转要可点击走通

## 2. 入口层

### P01 落地页
**功能**：
- 展示 slogan："别人给孩子一个 AI 工具，我们给孩子一支 AI 队伍，以及成为队长的责任。"
- 两个入口按钮："开始建队" / "已有队伍，登录"
- 简要展示产品是什么：3 步图示——定义队伍 → 参战赛题 → 社区成长
- 不需要登录即可浏览此页

### P02 登录
**功能**：
- 用户名 + 密码输入
- "登录"按钮
- "通过邀请加入"链接（跳转邀请码输入）
- 登录成功后跳转 P04 组队室主页（首次登录跳 P03 引导）

### P03 首次建队引导
**功能**：
- 分步引导，共 4 步：
  1. 给队伍起名（输入框 + "我的 AI 队伍"占位）
  2. 写一句话描述队伍要干什么（输入框）
  3. 选择起步模板（展示四角色模板卡片：侦察员/点子员/搭建员/挑刺员，点击选中）
  4. 确认并创建（展示摘要，"创建队伍"按钮）
- 创建成功后跳转 P04

## 3. Studio（组队室）

### P04 组队室主页（队伍概览）
**功能**：
- 顶部导航栏：TeenX logo / Studio / 赛题 / 排行榜 / 论坛 / 我的
- 队伍信息卡：
  - 队伍名（可点击编辑）
  - 队伍简介（可点击编辑）
  - 当前模型：DeepSeek（只读展示，不可改）
  - 版本数（数字，点击跳 P10）
  - "封存当前版本"按钮
- 队员卡片网格：
  - 每张卡片显示：队员名 / 角色模板标签 / 工具数量 / Skill 数量 / 最近活动时间
  - 点击卡片跳 P05 队员详情
  - 网格末尾有"+ 加队员"卡片，点击跳 P06
- 底部快捷入口：
  - "试跑一次"按钮 → 跳 P08
  - "查看活动记录"链接 → 跳 P11

### P05 队员详情/编辑
**功能**：
- 队员名（可编辑，输入框）
- 角色模板标签（下拉切换：侦察员/点子员/搭建员/挑刺员/自定义）
- 职责描述（多行文本，可编辑，模板有默认值）
- 工具清单（从工具库多选，展示已选工具标签，"管理工具"按钮跳 P07 工具库的选器模式）
- Skill 清单（展示已挂 Skill 标签，可移除，"添加 Skill"按钮弹出可选列表）
- 协作关系（展示当前队员向谁汇报、能委托给谁，可下拉选其他队员）
- "保存"按钮 / "取消"按钮
- "删除此队员"按钮（二次确认弹窗：删除后历史版本不受影响，确认删除？）
- 删除后队员数若 ≤1，禁止删除，按钮置灰

### P06 加队员（模板选择）
**功能**：
- 展示角色模板卡片网格：
  - 侦察员（Scout）：查清事实、找约束 / 默认工具：搜索、读文件
  - 点子员（Inventor）：出主意、想方案 / 默认工具：搜索、画图
  - 搭建员（Builder）：把方案做出来 / 默认工具：写代码、画图、写文档
  - 挑刺员（Critic）：挑毛病、质检 / 默认工具：读文件、跑测试
  - "自定义角色"卡片
- 点击某模板后：
  - 弹出起名输入框
  - "使用此模板创建"按钮
- 创建成功后跳回 P04，新队员出现在网格里
- 队伍已达 8 人时，此页显示"队伍已满（上限 8 人）"，禁止添加

### P07 工具库
**功能**：
- 展示所有可选工具列表（mock 数据，如：搜索/写代码/画图/读文件/跑测试/写文档/翻译/总结/生成图片/分析数据）
- 每个工具有：名称 / 一句话描述 / 类别标签
- 可按类别筛选（搜索类 / 生成类 / 分析类 / 文件类）
- 可搜索工具名
- 在"选器模式"下（从 P05 跳来时）：每个工具有勾选框，已选的工具高亮，底部"确认"按钮跳回 P05

### P08 试跑
**功能**：
- 展示预置试跑任务列表（3 个）：
  1. "自我介绍"——让队伍协作产出一段队伍自我介绍文字
  2. "做个待办清单"——让队伍做一个简单的待办清单
  3. "点子风暴"——让队伍围绕给定主题产出 3 个点子
- 每个任务卡片有：任务名 / 一句话描述 / "开始试跑"按钮
- 点击"开始试跑"后：
  - 展示"队伍即将执行此任务"确认页
  - 当前队伍成员列表（只读）
  - "启动"按钮 → 进入加载状态 → 跳转 P09 试跑结果

### P09 试跑结果
**功能**：
- 顶部：试跑任务名 + 完成状态（已完成/进行中/失败）
- 活动记录时间流：
  - 按时间倒序展示每个队员的动作
  - 每条记录：队员名 / 动作类型（搜索/生成/分析/质检等）/ 动作内容摘要 / 时间戳
  - 可展开查看详情
- 产物展示区：
  - 展示最终产物（文本/图片/文件，根据任务类型 mock）
  - "下载产物"按钮（mock）
- 底部操作：
  - "封存当前版本"按钮 → 弹出"给这个版本起个名字"输入框 → 确认后跳 P10
  - "回到组队室继续改"按钮 → 跳 P04
  - "再试跑一次"按钮 → 跳 P08

### P10 版本历史
**功能**：
- 版本列表（按时间倒序）：
  - 每条：版本名 / 封存时间 / 队员数 / 试跑次数
  - 当前 Stable 版本有"当前版本"标记
  - 点击某版本 → 展开该版本的队伍快照（队员列表 + 配置摘要，只读）
- 操作：
  - "设为当前版本"按钮（切回 Stable，二次确认）
  - "基于此版本创建新分支"按钮（mock，跳 P04 并提示"已基于 vX.X 创建草稿"）

### P11 活动记录
**功能**：
- 全队活动时间流（按时间倒序）：
  - 每条：时间 / 队员名 / 动作类型 / 动作摘要
  - 可按队员筛选（顶部有队员头像筛选条）
  - 可按动作类型筛选（全部/搜索/生成/分析/质检/协作）
- 分页加载（mock 20 条）

## 4. 赛题

### P12 赛题列表
**功能**：
- 赛题列表（按发布时间倒序）：
  - 每条卡片：赛题名 / 发布时间 / 截止时间 / 状态（报名中/进行中/已结束）/ 参赛人数 / "查看详情"按钮
- 顶部筛选：全部 / 报名中 / 进行中 / 已结束
- 顶部公告条："下一场赛题将于 X 月 X 日发布"

### P13 赛题详情/参战
**功能**：
- 赛题标题
- 赛题描述（markdown 文本展示）
- 赛题要求：
  - 产出形态说明（如"做一个 3 分钟微工具"/"写一篇分析报告"）
  - 评分维度说明
  - 完成时限
- 参战区：
  - 展示当前队伍配置摘要（队员列表 + 当前版本号）
  - "让队伍参战"按钮 → 二次确认"参战后将封存当前版本，不可修改，确认？"
  - 参战后状态变为"已参战，等待执行"
  - 展示执行进度（mock：排队中/执行中/已完成）
- 历史参赛记录（若参加过此赛题的往期版本）：
  - 列表展示历次成绩

### P14 赛题成绩
**功能**：
- 成绩卡：
  - 赛题名 / 参赛时间 / 最终得分（大字）
  - 各维度分项得分（如：唯一性 40/40 / 真实性 35/40 / 完整性 18/20）
  - 排名（如"第 3 名 / 共 12 人"）
- 诊断报告：
  - 失败模式说明（若有）
  - 建议改进方向（如"侦察员信息收集不足，建议增加搜索工具"）
- 产物回看：
  - 展示参赛时的产物（只读）
  - 活动记录回看（只读时间流）
- 操作：
  - "基于此次成绩 Fork 新版本"按钮 → 跳 P04 并提示"已基于参赛版本创建草稿"
  - "回到赛题列表"按钮

## 5. 排行榜

### P15 用户总积分榜
**功能**：
- 排名列表（按总积分倒序）：
  - 每条：排名 / 队长名（匿名昵称）/ 队伍名 / 总积分 / 参赛场次 / 胜场
  - 前 3 名有特殊标记（金银铜，但用文字标"第 1/2/3 名"即可，不做视觉特效）
  - 点击某用户跳 P23 用户主页
- 自己的排名固定置顶展示（"我的排名：第 X 名，积分 XXX"）
- 筛选：全部 / 本赛季 / 历史总榜
- 分页加载

### P16 Agent 赛题效果榜
**功能**：
- 排名列表（按 Agent 平均得分倒序）：
  - 每条：排名 / 队伍名（带队长匿名昵称）/ Agent 版本号 / 平均赛题得分 / 参赛场次 / 最高单场得分
  - 点击某条展开：该 Agent 的历次赛题成绩列表
- 自己的 Agent 排名固定置顶
- 筛选：按赛题筛选（下拉选某场赛题，看该场赛题的 Agent 排名）
- 分页加载

## 6. 论坛社区

### P17 论坛首页
**功能**：
- 顶部：论坛标题"TeenX 社区"
- 分类导航条（横向）：全部 / 作品分享 / 经验交流 / 提问求助 / 官方公告 / 水区
- 帖子列表（按最新回复时间倒序）：
  - 每条：标题 / 发帖人（匿名昵称）/ 发帖时间 / 回复数 / 点赞数 / 分类标签
  - 带有"AI 协助撰写"标记的帖子在标题旁显示标记文字
  - 带有"AI 已审"标记的帖子在底部显示标记文字
  - 点击跳 P19 帖子详情
- "发帖"按钮（悬浮在右下或顶部）→ 跳 P20

### P18 分类页
**功能**：
- 顶部：分类名 + 分类描述
- 帖子列表（同 P17，但只显示该分类的帖子）
- 排序：最新发布 / 最新回复 / 最多点赞
- "在此分类发帖"按钮 → 跳 P20 并预选该分类

### P19 帖子详情
**功能**：
- 帖子标题
- 发帖人信息：匿名昵称 / 发帖时间 / "AI 协助撰写"标记（若有）
- "AI 已审"标牌（帖子底部）
- 帖子正文（markdown 渲染）
- 互动区：
  - 点赞按钮 + 点赞数
  - 收藏按钮
  - 举报按钮
- 回复区：
  - 回复列表（按时间正序）：每条回复有 回复人昵称 / 回复时间 / 正文 / "AI 已审"标记 / 点赞
  - 回复输入框 + "发表回复"按钮
  - 回复也显示"AI 已审"标记，但不显示"AI 协助撰写"（回复是用户直接写的）
- 底部：
  - "发私信给 TA"按钮 → 跳 P22 并预选收件人
  - "查看 TA 的主页"链接 → 跳 P23

### P20 发帖（写帖 Agent）
**功能**：
- 顶部说明："你的写帖 Agent 会根据你的想法自动扩写成帖子"
- 输入区：
  - 分类选择（下拉：作品分享/经验交流/提问求助/水区）
  - "你想表达什么？"大文本框（用户输入想法/意图，可以是一句话也可以是一段要点）
  - "关联项目"选择器（可选，从队伍历史试跑/赛题记录里选一个作为素材来源）
  - "让 Agent 写帖"按钮
- Agent 生成区（点击"让 Agent 写帖"后展示）：
  - 加载状态
  - 生成完成后展示：帖子标题（可编辑）+ 帖子正文（可编辑，markdown 编辑器）
  - "重新生成"按钮
  - "发布"按钮 → 发布后跳 P19
  - "保存草稿"按钮（mock）
- 说明文字："发布后帖子会标记为'AI 协助撰写'，并经过 AI 审核"

### P21 私信列表
**功能**：
- 私信对话列表（按最新消息倒序）：
  - 每条：对方匿名昵称 / 最后一条消息摘要 / 时间 / 未读标记
  - 点击跳 P22
- "发新私信"按钮 → 跳 P22 空白对话（需选收件人）
- 私信不显示"AI 协助撰写"或"AI 已审"标记

### P22 私信对话
**功能**：
- 顶部：对方匿名昵称 / "查看 TA 的主页"链接 / "举报"按钮
- 消息流（按时间正序）：
  - 每条：发送人（自己/对方）/ 消息内容 / 时间
  - 左右气泡区分自己/对方
- 输入区：
  - 文本输入框
  - "发送"按钮
  - 输入框下方提示："私信内容不会经过 AI 审核，请文明交流。禁止发送外部链接、邮箱或手机号。"
  - 若输入内容含外部链接/邮箱/手机号模式，发送按钮置灰并显示提示
- 私信不显示"AI 协助撰写"或"AI 已审"标记

### P23 用户主页
**功能**：
- 用户信息：
  - 匿名昵称
  - 队伍名（若该用户公开展示）
  - 总积分 / 排名 / 参赛场次 / 胜场（从 P15 榜单数据来）
  - 加入时间
- TA 的帖子（该用户发布的帖子列表，跳 P19）
- TA 的赛题成绩（公开展示的，若用户选择公开）：
  - 列表展示：赛题名 / 得分 / 排名 / 时间
- 互动按钮：
  - "发私信给 TA"按钮 → 跳 P22
  - "关注"按钮（mock，点击后变"已关注"）

## 7. 个人

### P24 个人中心
**功能**：
- 我的队伍摘要：队伍名 / 版本数 / 队员数 / 总试跑次数（点击跳 P04）
- 我的赛题记录：
  - 列表：赛题名 / 得分 / 排名 / 时间（点击跳 P14）
  - 空状态："还没有参赛记录，去看看赛题"
- 我的论坛活动：
  - 我发的帖（列表，跳 P19）
  - 我的回复（列表，跳对应帖子的 P19）
- 我的私信入口（未读数，点击跳 P21）
- 快捷入口：
  - "去组队室"按钮 → P04
  - "看赛题"按钮 → P12
  - "看排行榜"按钮 → P15

### P25 设置
**功能**：
- 账号设置：
  - 匿名昵称（可改）
  - 密码修改（mock）
- 隐私设置：
  - "公开展示我的赛题成绩"开关
  - "公开展示我的帖子"开关
  - "允许陌生人私信"开关（默认开，可关）
  - "允许出现在用户目录"开关
- 通知设置：

## 11. 约束

- **不涉及任何视觉设计风格**——颜色、字体、间距、圆角等全部用基础默认值即可，这是功能原型不是设计稿
- **不接真实 API**——全部用 mock 数据
- **不做后端逻辑**——所有操作（如"封存版本""发帖"等）只做前端状态变化或弹提示
- **不做动画/过渡效果**
- **不做响应式适配**——桌面端一个尺寸即可
- **不实现真实的写帖 Agent 生成**——发帖页点击"让 Agent 写帖"后直接展示一段 mock 帖子内容
